# Interview Questions — Senior Data Engineer

## System Design (pick 1-2)
- Design a real-time event processing system that handles 100K events/sec
- How would you build a data quality framework for a large data lake?
- Design a CDC pipeline from multiple OLTP databases to a data warehouse

## Technical Deep Dive
- Walk me through how you'd debug a pipeline that's running 3x slower than usual
- What are the tradeoffs between micro-batch and true streaming?
- How do you handle schema evolution in a production pipeline?
- Explain exactly-once semantics in Kafka — how does it work under the hood?

## Practical / Coding
- Write a Python script to detect data drift between two table snapshots
- Given a messy JSON log file, parse and aggregate it into a summary
- Write a SQL query to find gaps in a time-series dataset

## Behavioral
- Tell me about a time a pipeline failed in production — what happened and what did you learn?
- How do you prioritize when multiple teams need data changes simultaneously?
- Describe a technical decision you made that you later regretted

## What we're looking for
- Strong fundamentals in distributed systems
- Practical experience with at least one orchestration tool
- Understanding of data modeling and warehouse design
- Good communication — can explain complex systems clearly
- Ownership mindset — doesn't just build, also operates
